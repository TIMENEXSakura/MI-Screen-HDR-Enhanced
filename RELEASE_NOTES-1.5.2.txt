小米截屏HDR增强 1.5.2
MI Screen HDR Enhanced

本次更新修正安装与导出流程，让两种操作各自完成你选择的任务。

功能改进

- 自动识别并安装：查找当前手机的运行库，生成并刷入挂载模块，继续显示管理器原始安装日志。
- 选择 SO 文件并导出：修补选定文件，只保存 ZIP，不在当前手机安装；可为原始库对应的其他设备准备模块。
- 修复手动选择其他设备的库时，被错误拦截并提示无法识别的问题。
- 导出完成显示保存位置、独立的导出进度和结果；不会把“已导出”记成“已安装”。
- 导出包在目标手机安装时自动查找对应库，支持不同的系统库位置；库不一致时给出明确原因。
- 保留 1.5.1 的 HDR 截图与预览、裁切及带壳保存、流动辉光、亮度比例调整等功能。

使用方式

主页 → 安装与导出：
- 当前手机使用：选择“自动识别并安装”，点击“安装”。
- 选择文件生成包：选择“选择 SO 文件并导出”，点击“修补并导出”。

导出包保存到 Download/MI-Screen-HDR-Enhanced/。
将 ZIP 交给原始库对应设备，在它的 Magisk、KernelSU / SukiSU 或 APatch 管理器中安装。
安装与导出的完整日志都保存在 Download/MI-Screen-HDR-Enhanced/logs/。

使用条件与兼容范围

需要 Android 14 及以上、ARM64、小米系统截屏、Root，以及支持 API 102 的 LSPosed。
导出包适用于原始库内容一致的系统；系统更新后库发生变化，需要重新导出。
沿用现有挂载方式；实际刷入后仍需手动重启设备。导出本身不需要重启。
不同固件及截屏版本的效果可能不同；部分流媒体平台的杜比视界内容仍可能出现 HDR 增益信息缺失或偏弱。
